# Quiz App

A quiz application built with HTML, CSS and JavaScript that tests 
your knowledge across multiple categories.

## Features
- Multiple categories and difficulty levels
- 15 second countdown timer per question
- Score tracking with correct and wrong count
- Saves your last preferences using localStorage
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- Open Trivia DB API
